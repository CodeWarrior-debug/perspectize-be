# Responsive Design Audit — February 2026

> Visual audit performed at 375px (mobile), 520px (min Chrome window), 768px (tablet), and 1440px (desktop) against the deployed app at `perspectize-fe-rf767.sevalla.page`.

---

## Critical Issues (P0 — Blocks mobile usability)

### 1. Header: User selector takes too much space on mobile
- **Viewport:** <640px
- **Component:** `Header.svelte` → `UserSelector.svelte`
- **Problem:** The `Select` trigger has a fixed `w-48` (192px) class. At 375px viewport with 16px gutters on each side, this leaves barely any room for the logo and action buttons. The header items are cramped.
- **Design spec says:** "Mobile: icon-only buttons (user icon, plus icon) — text labels hidden"
- **Fix:** Make the select trigger responsive — `w-32 sm:w-48` or use an icon-only trigger on mobile.

### 2. AG Grid column headers truncated/unreadable on mobile
- **Viewport:** <640px
- **Component:** `ActivityTable.svelte`
- **Problem:** At xs/sm tiers, the "Type" column header shows as "T..." and "Channel" shows as "Chann..." — both are unreadable truncated strings. The column headers with filter icons are too compressed.
- **Design spec says:** xs tier should show only Item + Type columns, sm adds Channel.
- **Fix:** Increase `minWidth` for Type column header at small sizes, or hide filter icons on mobile, or abbreviate header names based on tier.

### 3. AG Grid card container has no horizontal breathing room on mobile
- **Viewport:** <640px
- **Component:** `+page.svelte`
- **Problem:** The grid card (`border rounded-lg shadow-sm`) goes nearly edge-to-edge. While the page has `px-4` gutters, the card itself has zero inner padding. Combined with the grid's own borders, this creates a cramped, edge-hugging appearance.
- **Design spec says:** "Card: 0px horizontal margin (edge-to-edge within the 16px page gutters)" — this is correct, but the AG Grid internally needs its cells to breathe.

## Major Issues (P1 — Degrades experience significantly)

### 4. "Activity" title centered with no subtitle or search bar
- **Viewport:** All
- **Component:** `+page.svelte`
- **Problem:** The page title "Activity" is `text-3xl font-bold text-center` with no subtitle, no search bar, and no visual hierarchy. The design spec calls for:
  - Left-aligned title with subtitle "Recently updated content"
  - Search bar inline on desktop, stacked below on mobile
- **Fix:** Add subtitle, left-align title, add search input that integrates with AG Grid filtering.

### 5. Pagination controls: layout breaks and info missing on mobile
- **Viewport:** <640px
- **Component:** `ActivityTable.svelte` pagination section
- **Problem:**
  - "60 total" text floats alone on the left
  - Page size selector is hidden (`hidden md:flex`) — good for space, but there's no indication of page size
  - Prev/Next buttons show `<` and `>` which are tiny tap targets
  - The pagination and total count are on separate lines taking too much space
- **Fix:** Consolidate into a single row: `60 total · Page 1 of 6 < >` with better tap targets.

### 6. No page subtitle or context text
- **Viewport:** All
- **Component:** `+page.svelte`
- **Problem:** The design spec specifies "Recently updated content" as a subtitle under "Activity". Currently absent. This leaves the page feeling bare, especially on mobile where fewer columns are visible and users need context.
- **Fix:** Add subtitle text in muted-foreground color.

### 7. AG Grid row height doesn't adapt to mobile
- **Viewport:** <640px
- **Component:** `ActivityTable.svelte` theme config
- **Problem:** Row height is fixed at 44px. On mobile where titles are long and truncated, rows feel cramped. The touch target is adequate but the text truncation is aggressive.
- **Design spec says:** No explicit mobile row height, but mobile-first design suggests slightly taller rows for touch targets.
- **Fix:** Consider dynamically adjusting `rowHeight` based on responsive tier, or at minimum ensure text has adequate padding.

## Moderate Issues (P2 — Polish)

### 8. Header buttons: "New User" and "Add Video" text labels visible at narrow tablet
- **Viewport:** 445–640px (sm tier)
- **Component:** `FormPopover.svelte`
- **Problem:** The `hidden sm:inline` on button labels means text appears at 640px+, but at 445–639px the icon-only buttons look orphaned without clear labels. The threshold should be higher — text should probably only appear at `md` (768px+).
- **Fix:** Change `hidden sm:inline` to `hidden md:inline` for consistency with the header's available space.

### 9. Pagination: "Previous"/"Next" text vs arrow inconsistency
- **Viewport:** All
- **Component:** `ActivityTable.svelte`
- **Problem:** Uses `hidden sm:inline` for "Previous"/"Next" with `<`/`>` fallback. At the sm breakpoint (640px), the full text appears but the buttons are still small. The design spec shows `< >` always.
- **Fix:** Use left/right chevron icons from Lucide instead of text/characters for a cleaner look at all sizes.

### 10. No empty state design
- **Viewport:** All
- **Component:** `ActivityTable.svelte` / `+page.svelte`
- **Problem:** When there's no data, AG Grid shows "No items" — a bare text overlay. The design spec calls for an illustrated empty state with icon + message + CTA button.
- **Fix:** Add a proper empty state component (lower priority, noting for completeness).

### 11. Type column icon (YouTube play button) takes too much width on mobile
- **Viewport:** <640px
- **Component:** `ActivityTable.svelte` → `typeCellRenderer`
- **Problem:** The Type column shows a red YouTube play icon ⊙ that, combined with the column's `minWidth: 60`, takes up space that could be used by the Item title. On mobile every pixel counts.
- **Fix:** Consider hiding the Type column entirely on xs tier (only show Item), or making the icon smaller.

### 12. Date formatting wastes space on tablet
- **Viewport:** 640–900px (md tier)
- **Component:** `ActivityTable.svelte` formatting utilities
- **Problem:** Dates show as "Jul 18, 2010" — but at md tier where space is limited, showing "Feb 13, 20..." (truncated year) looks broken. Should use short format like "Jul 2010" or "7/18/10".
- **Fix:** Use a condensed date format at md tier.

## Minor Issues (P3 — Nice to have)

### 13. Font inconsistency in AG Grid cells
- **Problem:** AG Grid theme sets `fontFamily: "'Geist', system-ui, sans-serif"` for all cells. Per design spec, table cell text (video titles, descriptions) should use Charter (serif), while headers use Geist.
- **Fix:** Apply Charter font to AG Grid cell content via CSS override for body text cells.

### 14. No viewport meta tag verification
- **Problem:** Need to verify the HTML shell has proper `<meta name="viewport" content="width=device-width, initial-scale=1">`. Without this, mobile browsers won't respect responsive breakpoints.
- **Fix:** Check `app.html`.

### 15. Header logo area has no hover/active state feedback on mobile
- **Problem:** The "Perspectize" text link has `hover:text-primary-foreground/80` which is subtle. On mobile where there's no hover, there should be a tap/active state.
- **Fix:** Add `active:opacity-80` or similar for mobile touch feedback.
