## Decisions Made

1. **Date column uses agTextColumnFilter (not agDateColumnFilter)** - Our valueFormatter converts dates to locale strings, so the filter operates on formatted string values. Using agDateColumnFilter would require raw Date objects which we don't provide.

2. **Filters added to hidden columns** - Channel, createdAt, updatedAt, tags, and description columns all got agTextColumnFilter and floatingFilter enabled for search capability even though they're hidden by default.

3. **h-full w-full required for cell centering** - AG Grid cells have their own layout that doesn't automatically fill with flexbox children. Adding h-full w-full to the container div ensures the flexbox centering fills the entire cell.
