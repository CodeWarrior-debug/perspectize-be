**ActivityTable.svelte — Mobile column visibility (M-01):**

Add a responsive breakpoint listener that shows/hides columns based on viewport width.

1. Add a `$state` variable: `let isMobile = $state(false);`
2. Add an `$effect` that sets up a `matchMedia('(max-width: 767px)')` listener:
```typescript
$effect(() => {
  const mq = window.matchMedia('(max-width: 767px)');
  const handler = (e: MediaQueryListEvent | MediaQueryList) => {
    isMobile = 'matches' in e ? e.matches : (e as MediaQueryListEvent).matches;
  };
  handler(mq);
  mq.addEventListener('change', handler);
  return () => mq.removeEventListener('change', handler);
});
```

3. Add another `$effect` that reacts to `isMobile` and `gridApi` to show/hide columns:
```typescript
$effect(() => {
  if (!gridApi) return;
  if (isMobile) {
    // Show only Item and Type on mobile
    gridApi.setColumnsVisible(['duration', 'views', 'likes', 'publishDate', 'channel', 'createdAt', 'updatedAt', 'tags', 'description'], false);
    gridApi.setColumnsVisible(['item', 'type'], true);
  } else {
    // Restore default visibility (6 visible columns)
    gridApi.setColumnsVisible(['item', 'type', 'duration', 'views', 'likes', 'publishDate'], true);
    // Hidden columns stay hidden
    gridApi.setColumnsVisible(['channel', 'createdAt', 'updatedAt', 'tags', 'description'], false);
  }
});
```

**M-03: Header buttons icon-only at <768px**

The FormPopover component renders the trigger button with both an icon and a text label:
```svelte
<PopoverTrigger class={buttonVariants(...)}>
  {@render triggerIcon()}
  {triggerLabel}
</PopoverTrigger>
```

To make the text hidden on mobile, wrap the label text in a span with responsive visibility:

In FormPopover.svelte, change:
```svelte
{triggerLabel}
```
to:
```svelte
<span class="hidden sm:inline">{triggerLabel}</span>
```

This hides the text label at <640px (sm breakpoint), showing only the icon.

Also ensure the trigger button uses `size: 'icon'` on mobile. Since we can't dynamically change the buttonVariants size based on viewport in the class string, use a different approach:
- Keep the current buttonVariants call

Alternatively, simpler approach: Just hide the label text. The button with just an icon will naturally collapse to icon size since it uses flex layout. Ensure the trigger has `gap-2` between icon and text (already does via buttonVariants).
