## Decisions Made

**Mobile breakpoint at 767px:** Matches Tailwind's md: breakpoint (768px) for consistency with existing responsive utilities throughout the codebase.

**CSS-based thumbnail hiding:** Using CSS media query instead of JavaScript for performance and simplicity - no need to re-render cell when viewport changes, just hide via display:none.

**Column visibility strategy:** Desktop shows Item, Type, Length, Views, Likes, Date (6 columns). Mobile shows only Item and Type (2 columns) for essential information on narrow screens.
