    2. **Create GlassesIcon.svelte** at `frontend/src/lib/components/GlassesIcon.svelte`:
       - Use Svelte 5 `$props()` rune — accept `shape`, `color`, `size`, `class` props
       - Default: `shape = 'sunglasses'`, `color = 'purple'`, `size = 24`
       - Generate unique gradient ID per instance using `crypto.randomUUID().replace(/-/g, '').slice(0, 8)` — this is NOT reactive, computed once at init

       - Always use light mode stops (dark mode deferred per CONTEXT.md)
       - Use `$derived` for viewBox based on shape:
         - sunglasses: `0 0 70 28`
         - round: `0 0 56 28`
         - oval: `0 0 62 28`
       - SVG: set `height={size}` only (let width auto-scale from viewBox aspect ratio). Remove explicit `width` attribute. Add `style="height: {size}px"` and let viewBox + preserveAspectRatio handle width.
       - Use `{#if shape === 'sunglasses'}` / `{:else if shape === 'round'}` / `{:else}` blocks for the three SVG path sets from REFERENCE-glasses.md
       - Add `aria-hidden="true"` on the SVG (decorative)
       - Use `class={className}` for passthrough CSS classes
       - Reference the exact SVG paths from REFERENCE-glasses.md but replace hardcoded fill/stroke with dynamic values using the palette and gradient ID

    **SVG paths (from REFERENCE-glasses.md):**

    - **Oval (62x28):** Two ellipses cx=16,48 rx=13 ry=10 + bridge arc

    **Critical:** Each `<linearGradient id={gradientId}>` and `fill="url(#{gradientId})"` must use the unique per-instance ID. Stop opacities differ by shape: sunglasses 0.5/0.9, round 0.45/0.85, oval 0.45/0.85.
