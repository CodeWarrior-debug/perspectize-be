# Phase 3.4: Perspectize Branding & Glasses Identity - Context

**Gathered:** 2026-02-18
**Status:** Ready for planning

<domain>
## Phase Boundary

Establish the Perspectize brand identity through the glasses motif — a `<GlassesIcon>` Svelte component with 3 shapes (sunglasses, round pince-nez, oval pince-nez), a preset color palette picker, user preferences storage (JSONB), glasses shown in user avatars, and a skippable onboarding prompt. SVG reference designs are in `REFERENCE-glasses.md`.

**Not in scope:** Jeeves AI assistant personality/chat UI (future phase), app-wide theming (accent colors, light/dark mode — separate phase), profile page.

</domain>

<decisions>
## Implementation Decisions

### Glasses Picker UX
- Picker lives in a **popover near the user avatar** (consistent with existing AddVideo/CreateUser popover pattern)
- Shape toggle: **Claude's discretion** — pick the best UX pattern for the space (cards vs icon row)
- Color palette: **6-8 curated color swatches** — each defines stroke + gradient stops for both light/dark mode
- **Inline preview** updates live as user toggles shape/color
- No randomize button — keep it simple
- Color picker is the first step toward a future "choose theme" feature (glasses color now, app accent/dark mode later)

### Avatar Display & Sizing
- Glasses appear in **two locations**:
  1. **Header UserSelector** — glasses icon for the current user
  2. **AG Grid perspective rows** — glasses shown only for the **current user's** perspectives, not every user's
- **Default state:** Random glasses assigned (random shape + purple color) — everyone starts with glasses, no blank states
- **Sizing:** Claude's discretion — pick appropriate sizes per context (header vs table row)
- **Icon library:** TBD — user evaluating Lucide (current), Phosphor, Tabler. Decision pending. Currently using `@lucide/svelte`.

### Onboarding Flow
- Triggers on **first time selecting a user** from UserSelector
- **Skippable** — show glasses picker popover with a skip/dismiss option
- If skipped, random defaults remain (user can change later)
- Accessible later via **avatar click** in header (same popover)
- No dedicated onboarding page — popover is sufficient

### Storage
- JSONB `preferences` column on user table: `{"glasses": {"shape": "oval", "color": "purple"}}`
- Go API endpoint to persist/retrieve glasses preferences
- Extensible for future preferences (theme, typography, etc.)

### Claude's Discretion
- Shape toggle interaction pattern (visual cards vs icon row)
- Sizing strategy across contexts (fixed sizes vs responsive prop)
- SVG optimization for the 3 shapes (inline vs component-per-shape)
- Loading/transition animations for glasses preview

</decisions>
