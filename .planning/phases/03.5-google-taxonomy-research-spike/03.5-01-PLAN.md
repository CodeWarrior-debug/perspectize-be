  <action>
Create a step-by-step exploration guide the user follows in Postman. This is a USER-FACING document, not a planning doc. Write it as instructions they follow interactively.

Structure:

**Prerequisites:**
- Google Cloud Project with Natural Language API enabled
- API Key from Google Cloud Console > APIs & Services > Credentials
- Postman installed
- Import the collection from `postman/google-nl-taxonomy-explorer.json`
- Set the `API_KEY` collection variable to your key

**Phase A: Validate API Access (5 min)**
- Run Curl 1 (V1 basic) -- confirm you get a response
- Run Curl 2 (V2) -- confirm you get multiple categories with hierarchy
- Compare V1 vs V2 output (V2 shows parent categories)

**Phase B: Explore Top-Level Coverage (15 min)**
- Run Curls 3-9 systematically
- For each response, record:
  - All top-level categories seen (first path segment)
  - Maximum depth observed
  - Any unexpected cross-categorization
- Goal: Confirm which of the 20 curated categories appear in practice

**Phase C: Deep-Dive Subcategories (20 min)**
- Pick 3-5 categories most relevant to your YouTube content
- Write custom Postman requests with text targeting specific subcategories
- Example: To explore `/Sports/Team Sports` deeper, write about specific sports, leagues, players
- Record the deepest paths you find
- Note where the taxonomy stops being useful (too generic or too niche)

**Phase D: YouTube Metadata Test (10 min)**
- Run Curl 10 (YouTube metadata format)
- Try with 2-3 of your own YouTube video title+description combos
- Evaluate: Does the classification match what you'd manually assign?
- Note confidence thresholds that feel "right" for primary vs secondary categories

**Phase E: Record Findings**
- List all unique category paths discovered
- Mark which ones are relevant to Perspectize YouTube content rating
- Note any gaps where user-created categories would be needed
- Decide: How many levels deep should the seed data go? (recommendation: 2-3 levels)

Include a findings template at the bottom they can fill in:
```
## My Findings

### Categories Discovered (copy paths from responses)
- /path/from/response (confidence: X.XX)

### Relevance Assessment
- KEEP: [paths to include in seed data]
- SKIP: [paths too niche or irrelevant]
- CUSTOM NEEDED: [gaps where user categories should go]

### Depth Decision
- Seed depth: [2 or 3 levels]
- Reasoning: [why]

### Confidence Threshold
- Primary category: [threshold, e.g., 0.5]
- Secondary/label: [threshold, e.g., 0.3]
```
