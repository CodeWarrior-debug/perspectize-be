       - Package `wikidata`
       - `Client` struct with: httpClient (*http.Client with 10s timeout), baseURL (string, default "https://www.wikidata.org/w/api.php"), userAgent (string, "Perspectize/1.0 (https://github.com/CodeWarrior-debug/perspectize)")
       - `NewClient()` constructor — no API key needed (Wikidata is free/public)
       - `Search(ctx context.Context, query, language string, limit int) ([]domain.WikidataSearchResult, error)`:
         - Build URL with params: action=wbsearchentities, search={query}, language={language}, format=json, type=item, limit={limit}
         - Default language to "en" if empty, default limit to 10 if <= 0
         - Create request with `http.NewRequestWithContext`
         - Set `User-Agent` header (MANDATORY per Wikidata policy — pitfall #1)
         - Set `Accept` header to "application/json"
         - Execute request, check status code
         - Parse JSON response. Define internal `searchResponse` struct matching Wikidata's response shape:
           - `Search` array of objects with `id` (Q-ID), `label`, `description` fields
           - Use flat `label` and `description` fields (not `display` object — pitfall #2)
         - Map response to `[]domain.WikidataSearchResult`
         - Include simple retry: on HTTP 429 or 5xx, retry up to 2 times with exponential backoff (1s, 2s). Use a simple for-loop retry, not a library.
       - Import `github.com/CodeWarrior-debug/perspectize/backend/internal/core/domain` for WikidataSearchResult type
       - Must satisfy `portservices.WikidataClient` interface
