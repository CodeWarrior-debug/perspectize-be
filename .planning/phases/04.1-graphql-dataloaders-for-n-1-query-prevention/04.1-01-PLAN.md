  <name>Task 2: Create dataloadgen loaders package with per-request middleware</name>
  <files>

  <action>
    1. Install dataloadgen: `cd backend && go get github.com/vikstrous/dataloadgen@v0.0.10`

    2. Create `backend/internal/adapters/graphql/loaders/loaders.go` with:

       **Package structure** (all in one file per RESEARCH.md recommendation):

       a. **Context key type:** `type ctxKey string` with `const loadersKey = ctxKey("dataloaders")`

       b. **Loaders struct:**
          ```go
          type Loaders struct {
              UserLoader    *dataloadgen.Loader[int, *domain.User]
              ContentLoader *dataloadgen.Loader[int, *domain.Content]
          }
          ```

       c. **userBatcher struct** with `repo portrepos.UserRepository` field:
          - `batchUsers(ctx, ids []int) (map[int]*domain.User, error)` — calls `repo.GetByIDs`, builds `map[int]*domain.User` from results keyed by `u.ID`

       d. **contentBatcher struct** with `repo portrepos.ContentRepository` field:
          - `batchContent(ctx, ids []int) (map[int]*domain.Content, error)` — calls `repo.GetByIDs`, builds `map[int]*domain.Content` from results keyed by `c.ID`

       e. **NewLoaders(userRepo, contentRepo)** — creates fresh Loaders with `dataloadgen.NewMappedLoader` for each batcher, using `dataloadgen.WithWait(time.Millisecond)` option

       f. **Middleware(userRepo, contentRepo) func(http.Handler) http.Handler** — chi-compatible middleware that creates `NewLoaders` per request and injects into context via `context.WithValue`

       g. **For(ctx) *Loaders** — extracts Loaders from context, panics if missing (programming error = middleware not applied)

       h. **GetUser(ctx, id int) (*domain.User, error)** — convenience: calls `For(ctx).UserLoader.Load(ctx, id)`

       i. **GetContent(ctx, id int) (*domain.Content, error)** — convenience: calls `For(ctx).ContentLoader.Load(ctx, id)`

    3. Use `NewMappedLoader` (NOT `NewLoader`) — GORM `WHERE id IN` does not guarantee result order. NewMappedLoader handles ordering automatically and returns `dataloadgen.ErrNotFound` for missing keys.

    4. Import paths:
       - `github.com/vikstrous/dataloadgen`
       - `github.com/CodeWarrior-debug/perspectize/backend/internal/core/domain`
       - `portrepos "github.com/CodeWarrior-debug/perspectize/backend/internal/core/ports/repositories"`

    5. Run `cd backend && go build ./...` to verify compilation.
