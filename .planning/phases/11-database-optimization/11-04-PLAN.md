<objective>
Enable server-side sorting and filtering by wiring AG Grid callbacks to GraphQL query parameters backed by indexed columns.

Purpose: Currently AG Grid sorts/filters client-side on the loaded page of data only. Users sorting by "Views" only reorder the visible 10 rows, not the full dataset. This plan connects AG Grid's sort/filter events to server-side operations using the indexed columns from Plan 02, enabling correct full-dataset sorting and filtering.

Output: Extended GraphQL schema with ContentFilter input, repository filter application, AG Grid ↔ GraphQL refetch integration, .Select() optimization to exclude JSONB from list queries, and estimated count for pagination.
</objective>
