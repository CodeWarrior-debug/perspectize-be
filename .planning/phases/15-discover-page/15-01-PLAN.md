<objective>
Create the Discover page with YouTube search, result display, and one-click add to library.

Purpose: Users currently must find videos on YouTube externally, copy URLs, and paste them into Perspectize. This plan creates a /discover route with in-app YouTube search, reducing the add flow from 4+ clicks to 2 (search + click add). This is the MVP search experience.

Output: /discover route with SearchBar (debounced), SearchResults with thumbnails and metadata, SearchResultCard with Add to Library button, Load More pagination, and Header navigation update.
</objective>

1. Create `frontend/src/lib/services/youtubeApi.ts`:
   - Define TypeScript interfaces: SearchParams, SearchResponse, SearchResultItem
   - Implement `fetchYouTubeSearch(params: SearchParams): Promise<SearchResponse>`
     - Builds URL: `https://www.googleapis.com/youtube/v3/search`
     - Sets: `part=snippet`, `type=video`, `key=VITE_YOUTUBE_API_KEY`
     - Maps params: q, maxResults (25), pageToken, order
     - Throws on non-OK response with status code
   - Export query key factory:
     ```typescript
     export const youtubeKeys = {
       all: ['youtube'] as const,
       searches: () => [...youtubeKeys.all, 'search'] as const,
       search: (query: string, filters?: SearchFilters) =>
         [...youtubeKeys.searches(), query, filters] as const,
     };
     ```
