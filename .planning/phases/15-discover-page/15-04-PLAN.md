<tasks>
1. Add skeleton loading cards to VideoResultsGrid.svelte:
   - Create SkeletonCard: animated pulse placeholder matching VideoCard dimensions
   - Show 6 skeleton cards during initial fetch (search or trending)
   - Show 3 skeleton cards at bottom during "Load More" fetch
   - Use Tailwind `animate-pulse` with `bg-muted` backgrounds

2. Add empty state to VideoResultsGrid.svelte:
   - When query exists but results empty: "No results found for '{query}'"
   - Suggest: "Try different keywords or check your spelling"
   - When trending view returns empty (rare, e.g. regional quirk): "No trending content available right now"

3. Add error states to Discover page:
   - **Quota exceeded (403):** "YouTube API quota exceeded. Try again tomorrow or reduce search frequency."
   - **Network error:** "Unable to reach YouTube. Check your connection." + Retry button
   - **Generic error:** "Something went wrong." + Retry button
   - Retry button calls `queryClient.refetchQueries({ queryKey: youtubeKeys.searches() })` when in search view, or `queryClient.refetchQueries({ queryKey: youtubeKeys.trending() })` when in trending view

4. Add keyboard shortcuts to +page.svelte:
   - Register window keydown listener in $effect (cleanup on unmount)
   - Cmd+K (Mac) / Ctrl+K (Win) → focus search input
   - Escape → clear search query, returning the page to the Trending default view (view derives back to 'trending' once debouncedQuery is empty)
   - `e.preventDefault()` on matched shortcuts

5. Add lazy-load thumbnails to VideoCard.svelte:
   - Use IntersectionObserver to load thumbnail src only when card enters viewport
   - Placeholder: `bg-muted` div matching thumbnail dimensions (320x180)
   - Cleanup observer on component unmount

6. Write unit tests `frontend/src/tests/youtubeApi.test.ts`:
   - Test URL construction with all parameter combinations
   - Test query key factory produces correct keys
   - Test error handling for non-OK responses (mock fetch)
   - Test that VITE_YOUTUBE_API_KEY is included in URL
   - Mock global fetch for all tests

7. Write component tests `frontend/src/tests/SearchBar.test.ts`:
   - Test renders input with placeholder
   - Test debounce: typing triggers debouncedQuery after 300ms delay
   - Test clear button resets input and debouncedQuery
   - Test autofocus on mount
   - Use @testing-library/svelte and vi.useFakeTimers for debounce testing

8. Run `pnpm run test:run` in frontend/ to verify all tests pass
